## 📌 Executive Summary

This project delivers an enterprise-grade, interactive **Supply Chain & Inventory Performance Dashboard** built with **Python**, **Streamlit**, and **Plotly**. Analyzing over **15,000 transaction records**, the dashboard provides actionable business insights into inventory thresholds, operational profitability, lead-time bottlenecking, and supplier efficiency.
